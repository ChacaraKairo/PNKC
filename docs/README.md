# Documentacao e referencias

Esta pasta guarda arquivos de apoio que nao fazem parte do carregamento principal do site.

## Estrutura

- `references`: PDFs sobre plano de negocios usados como base para organizar secoes, campos e textos de ajuda.
- `media`: imagens originais e materiais de apoio que nao precisam ficar na raiz do projeto.

## Observacao

O site publicado depende apenas de:

- `index.html`
- `site-plano-de-negocios.html`
- `assets/`

Os arquivos em `docs/` podem ser mantidos no repositorio para consulta e evolucao futura do produto.
